# 安装指南（双系统）

**中文** | [English](en/installation.md)

请严格按照以下步骤操作。

## 前置条件

- 设备引导加载程序（bootloader）已解锁
- 设备当前仅安装 Android 系统（无其他 Linux 分区）

## 准备文件

1. 准备 rootfs 与 boot 镜像：从对应发行版的构建仓库获取（见仓库 README 的「支持的发行版」表），
   或使用本仓库 Releases 中已有的镜像。
   单系统请使用文件名带 `single` 的 boot 与 rootfs，双系统使用带 `dual` 的 rootfs。
2. 准备 `parted`：使用 TWRP 内置的版本，或从系统包 / 官方发布页获取。
   （本仓库不再附带该二进制文件）

---

## 安装步骤

### 1. 启动到 TWRP

```bash
adb reboot recovery
```

### 2. 推送 parted 文件

```bash
adb push <path/to/parted> /sdcard
```

### 3. 进入 adb shell

```bash
adb shell
```

### 4. 创建 Linux 分区

```bash
chmod +x /sdcard/parted
/sdcard/parted /dev/block/sda
```

在 parted 中执行以下操作：

```bash
print          # 查看分区列表，记下 userdata 的编号（最左边，例如 29）
rm 29          # 删除 userdata 分区

# 创建新分区（假设总存储 256GB，userdata 128GB，linux 128GB）
mkpart userdata ext4 12.7GB 140.7GB
mkpart linux ext4 140.7GB -0MB

#1T为各512G
mkpart userdata ext4 12.7GB 524.7GB
mkpart linux ext4 524.7GB -0MB

#512G为各256G
mkpart userdata ext4 12.7GB 262.35GB
mkpart linux ext4 262.35GB -0MB

print          # 确认新分区：29 为 userdata，30 为 linux
quit
```

### 5. 退出 shell 并重启到 bootloader

```bash
exit
adb reboot bootloader
```

### 6. 刷写镜像

```bash
fastboot erase dtbo_b
fastboot flash boot_b boot-*.img
fastboot flash linux rootfs-*.img
fastboot set_active b
fastboot reboot
```

### 7. 首次启动后扩展分区

进入 Linux 系统后，执行以下命令扩展分区至实际大小：

```bash
sudo resize2fs /dev/sda30
```

注意：默认 rootfs 镜像仅占 8GB，需手动扩容。

## 单系统启动

目前仅提供 Debian 的单系统镜像。

### 1. 刷写镜像

```bash
fastboot erase dtbo_ab
fastboot flash boot （你下载的boot）
fastboot flash userdata （你下载的rootfs）
fastboot reboot
```

### 2. 首次启动后扩展分区

进入 Linux 系统后，执行以下命令扩展分区至实际大小：

```bash
sudo resize2fs /dev/sda29
```

注意：默认 rootfs 镜像仅占 8GB，需手动扩容。
