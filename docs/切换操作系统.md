# 双系统切换

**中文** | [English](en/switching-os.md)

## 方法一：图形界面（需要 root）

通过 WoaManager 切换，工具来源于酷安 @游侠侠，[下载链接](https://wwl.lanzouq.com/b00eew9kbc)（提取码：`youx`），[原帖链接](https://www.coolapk1s.com/feed/57455997)。

**从 Android 到 Linux**

授予该软件 root 权限并打开，点击「切换到 linux」功能，这里列出了需要刷入的 boot 分区和需要擦除的 dtbo 分区，工具会自动识别；如未识别出请点击「分区管理」上的「读取分区」按钮刷新。

在「切换到 linux」下的 linux boot 路径上输入 Linux 系统的 dual-boot.img 所在的绝对路径。
（可使用 MT 管理器对 boot 文件长按出现选择框点击属性，长按名称或目录可获取文件的完整路径。）

输入完文件路径点击保存记录该路径，点击一键切换将自动刷入 boot、擦除 dtbo，并重启系统切换到 Linux 系统。

**从 Linux 到 Android**

确保在 Android 系统下打开该工具，点击「推送 linux 切换工具」，这里列出了需要备份的 boot 和 dtbo 所在分区，还有需要推送的 linux 分区。

在推送前软件需要你挂载 linux 分区，点击「挂载分区」，在新增挂载分区下选择 linux 分区并点击保存，默认挂载的分区目录为 `/data/mounted/linux`，保存后点击下方的挂载将挂载 linux 分区。

在「推送 linux 切换工具」处点击「一键推送工具」，将 boot、dtbo 和切换脚本 `.sh` 文件推送到 Linux 根目录的 `WoaManager` 文件夹内，软件也会提示需要使用 root 权限执行其中的 `.sh` 文件。

在 Linux 下执行切换脚本：

```bash
sudo /WoaManager/android.sh
```

脚本将刷入 Android 的 boot 和 dtbo 文件并重启切换到 Android 系统。

## 方法二：启动槽位切换

Bootloader 模式（需要其他设备辅助）。

**从 Android 到 Linux**

```bash
fastboot set_active b
fastboot reboot
```

**从 Linux 到 Android**

```bash
fastboot set_active a
fastboot reboot
```
