# Recommended GNOME extensions

[中文](../推荐的GNOME扩展.md) | **English**

For a better touch experience on the tablet, these GNOME extensions are recommended:

- [Auto Activities](https://extensions.gnome.org/extension/1018/auto-activities/)
- [Maximized by Default Actually Reborn](https://extensions.gnome.org/extension/4794/maximized-by-default-actually-reborn/)
- [Maximized Into Empty Workspace](https://extensions.gnome.org/extension/4970/maximized-into-empty-workspace/)
- [Overview Background](https://extensions.gnome.org/extension/4099/overview-background/)
- [Reorder Workspaces](https://extensions.gnome.org/extension/609/reorder-workspaces/)
- [TouchUp](https://extensions.gnome.org/extension/4945/touchup/)
