# 官方键盘支持（Pogo Pin）

**中文** | [English](en/keyboard.md)

1. 检查服务状态：

   ```bash
   sudo systemctl status sheng-devauth
   ```

2. 若未运行，启用并启动：

   ```bash
   sudo systemctl enable sheng-devauth
   sudo systemctl start sheng-devauth
   ```

3. 重新插拔键盘的 Pogo Pin 接口。
4. 再次检查服务，看到以下输出表示成功：

   ```
   Sent pad token to kernel driver!
   ```

5. 每次重启后都需要重新插拔 Pogo Pin，以完成键盘认证。
