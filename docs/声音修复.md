# 小米平板 6S Pro 音频修复流程

**中文** | [English](en/audio-fix.md)

## 1. 固件准备

将从 Android 系统下提取的 `cs35l43` 相关 `.wmfw` 和 `.bin` 文件，放入 Linux 系统的 `/lib/firmware/cirrus/` 目录下。

> 这些文件可从 Android 系统提取，或到上游仓库获取。

## 2. 固件重命名（解决加载错误）

在 `/lib` 目录下，运行以下命令补全驱动所需的命名：

```bash
cd /lib/firmware/cirrus/
for pos in BLH BLL BRL TLH TLL TRL; do
    sudo cp cs35l43-dsp1-spk-prot.wmfw "cs35l43-DSP1-spk-prot-(null)-${pos}.wmfw" 2>/dev/null
    sudo cp cs35l43-dsp1-spk-prot.wmfw "cs35l43-DSP1-spk-prot--(null)-${pos}.wmfw" 2>/dev/null
    sudo cp "${pos}-cs35l43-dsp1-spk-prot.bin" "cs35l43-DSP1-spk-prot-(null)-${pos}.bin" 2>/dev/null
    sudo cp "${pos}-cs35l43-dsp1-spk-prot.bin" "cs35l43-DSP1-spk-prot--(null)-${pos}.bin" 2>/dev/null
done
```

## 3. 音频链路初始化

执行以下命令建立音频矩阵路由并激活驱动：

```bash
# 启动 pd-mapper
pd-mapper &

# 建立虚拟矩阵跳线与设置音量
amixer -c 0 cset name='SECONDARY_MI2S_RX Audio Mixer MultiMedia1' 1
amixer -c 0 sset 'stream0.vol_ctrl0 MultiMedia1 Playback Volu' 80%

# 保存 ALSA 状态
alsactl store 0
```

## 4. 验证与排障

- **发声测试**：`speaker-test -D plughw:0,0 -c 2`
- **重置服务**：若桌面音频系统未显示输出设备，执行 `systemctl --user restart pipewire wireplumber`
- **挂载音频**：`pactl load-module module-alsa-sink device=hw:0,0`
